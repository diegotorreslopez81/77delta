# Web 77 Delta v1 · plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publicar en GitHub Pages la web de 77 Delta con las 19 páginas de la v1, replicando el mensaje en español de infinitelabs.co con la identidad de 77 Delta.

**Architecture:** Astro 7 estático con Tailwind v4. Un layout (`Base.astro`) con nav y footer; datos en módulos TypeScript bajo `src/data/`; páginas en `src/pages/`. Sin frameworks de UI ni librerías de animación: aparición al hacer scroll y contadores con IntersectionObserver en el layout.

**Tech Stack:** Astro 7.2.9, Tailwind 4.3, TypeScript strict, pnpm 11, GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-01-web-77delta-design.md`

## Global Constraints

- Idioma: castellano. Sin em-dashes (—) en ningún texto: usar guión normal o punto.
- Nunca «Infinite Labs» en ningún texto ni enlace. Nunca explicar el 77. Nunca añadir palabra de categoría al nombre.
- Sociedad: Next Gen Academy SL · CIF B44861649 · Carrer Penedès 27, 08184 Palau-solità i Plegamans, Barcelona. Ciudad: Barcelona. Nada de Tallinn ni Estonia.
- Color: solo tokens `tinta`, `tinta-honda`, `tinta-alta`, `oro`, `oro-tenue`, `marfil`, `pizarra`, `linea`. El oro es acento (botón, eyebrow, Δ, una cifra), nunca relleno de bloques. Sin degradados.
- Tipografía: `font-display` (Sora) para titulares, `font-sans` (IBM Plex Sans) para texto, `font-mono` (IBM Plex Mono) para eyebrows y datos.
- Todos los enlaces internos pasan por `href()` de `src/lib/site.ts`. Los recursos de `public/` también (`href('/img/...')`).
- Copy de origen: ficheros `copy-es/*.txt` del scratchpad de la sesión (extraídos del git de `~/dev/website`). Cada fichero lleva nav y footer al principio y al final: ignorar esas partes, usar solo el contenido entre el `[h1]` y el bloque final «Consultora tecnológica especializada en PYMEs. Transformamos...».
- Verificación de cada tarea: `pnpm build` sin errores y `node scripts/check-links.mjs` sin enlaces rotos hacia las páginas de la tarea.
